      How I use AI, and where I don't trust it.

      It can work out a solution like a senior full-stack developer, then miss a beginner exploit like SQL injection. So I use it constantly and review everything.

      What I hand it.

      • Testing, design and research. Tests, frontend design, research, and breaking rough ideas into plans.
      • A daily security loop. It researches newly disclosed vulnerabilities, then I hunt for them in my own codebases.
      • My own rules. Claude skills I wrote for software architecture, development rules and security, so every session starts from them.

      • Security basics. In my testing it still forgets beginner exploits, most often SQL injection, so I check queries and inputs by hand.
